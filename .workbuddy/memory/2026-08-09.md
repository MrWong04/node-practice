**关键技术决策**：
- DeepSeek 用原生 fetch 流式解析（OpenAI 兼容），`streamChatCompletion` 为 AsyncGenerator
- 用户消息先入库，AI 完整回复流结束后才入库（不完整不入库）
- 跨用户资源访问返回 404（不泄露存在性）

**排障记录（重要）**：
1. Prisma 6.19 在 Windows 上 `safe-delete`（回收站删除旧 client）失败，且服务运行时 `query_engine-windows.dll.node` 被占用导致 `prisma generate` EPERM。解决：停掉 dev 服务（tsx watch 会自动重启，需 kill 进程链）→ 用 PowerShell `Remove-Item -Recurse -Force` 删 `.prisma`（沙箱 rm -rf 会触发 safe-delete 钩子失败）→ 重新 `prisma generate`。
2. tsconfig `baseUrl` 在 TS6 弃用导致 typecheck 失败（预先存在的问题），已加 `"ignoreDeprecations": "6.0"` 修复。
