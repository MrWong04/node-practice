# 2026-08-08 工作日志

## RDP 远程桌面排障（本机 DESKTOP-8ON0A3P，Windows 10 Pro 24H2，IP 192.168.5.144）

用户用手提电脑 RDP 连本机失败，且 ping 不通。排障过程与修复：

### 问题 1：ping 不通
- 原因：防火墙所有 ICMP 回显请求规则（`核心网络诊断 - ICMP 回显请求(ICMPv4-In)` 等）均为 `Enabled=False`
- 修复：`netsh advfirewall firewall set rule name="文件和打印机共享(回显请求 - ICMPv4-In)" new enable=yes`
- 结果：ping 恢复 ✅

### 问题 2：RDP 连不上（3389 不监听）
- 症状：TermService 服务显示 Running，但 3389 端口从不监听；事件日志报 `远程桌面服务启动失败 0x80070005（拒绝访问）`
- 排查链：防火墙规则正常（Profile=Any、Allow）→ 组策略无覆盖 → RDP-Tcp 键权限正常 → **发现 TermService 服务账户为 `NT Authority\NetworkService`（异常！应为 `LocalSystem`）**
- 修复：`Set-ItemProperty -Path 'HKLM:\SYSTEM\CurrentControlSet\Services\TermService' -Name 'ObjectName' -Value 'LocalSystem'`，然后重启 TermService/SessionEnv/UmRdpService 服务链
- 结果：3389 端口正常监听（TCP/UDP 0.0.0.0:3389）✅

### 环境备注
- 本机装有腾讯电脑管家（QQPCTray/QQPCRTP 运行中，路径 D:\电脑管家\QQPCMgr\），有多个自修复服务（13816/19967/24255.exe）。服务账户被改成 NetworkService 疑似与安全软件/优化工具有关，若 RDP 再出问题优先检查此项。
- WLAN 网络配置文件为 Public（公用网络），但远程桌面防火墙规则 Profile=Any 已放行。
- 诊断技巧：PowerShell 工具在此环境 stdout 回显异常，需用 `Out-File 临时文件 + Read` 方式读取结果。

### 问题 3：RDP 文件传输（方案一驱动器重定向未生效）
- 本机 RDP-Tcp 重定向配置全部允许（fDisableCdm/fDisableClip/fDisableCcm=0），但用户在手提 mstsc 里勾选"驱动器"后仍看不到共享盘符
- 排查：确认用户连接停在登录界面（SessionId=2 只有 LogonUI）且重定向盘符只出现在 RDP 会话内（非本机 Console 桌面）—— 典型误解点
- 解决方案改为 SMB 共享（用户采纳）

### 问题 4：配置 SMB 局域网共享（已完成 ✅）
- 创建共享：`New-SmbShare -Name 'SMB_Share' -Path 'D:\SMB_Share'`（Everyone 权限）
- 注意：`New-SmbShare -FullAccess` 参数在此环境报"参数错误"，需先创建共享再用 `Grant-SmbShareAccess -AccountName Everyone -AccessRight Full -Force` 授权；`Set-SmbShare -FullAccess` 也不支持
- NTFS 权限：用 .NET ACL（FileSystemAccessRule + Set-Acl）设置 Everyone FullControl
- 防火墙：`Get-NetFirewallRule -DisplayGroup '文件和打印机共享' | Set-NetFirewallRule -Enabled True`（启用 51 条规则含 SMB-In）
- 验证：`\\192.168.5.144\SMB_Share` 可访问，写入/读取成功（沙箱内 safe-delete 会拦 UNC 删除，属正常）
- 访问方式：手提电脑资源管理器输入 `\\192.168.5.144\SMB_Share`，凭据 Administrator + 密码
