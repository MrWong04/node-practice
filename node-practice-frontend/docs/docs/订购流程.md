## 立即订购

1. **确认订单**
   - 用户在产品详情页选择立即订购，进入确认订单页面。

2. **立即支付**
   - 用户确认订单后，选择立即支付，跳转至支付页面。

3. **支付完成**
   - 支付完成后，系统跳转至协议签署页面。

4. **手写签署区**
   - 用户在协议签署页面完成手写签署。
