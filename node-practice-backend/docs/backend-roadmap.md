## "后端入门"的行业标准

### 初级后端工程师（Junior Backend）

> 能独立设计、开发、部署一个包含以下功能的全栈项目：

- [x] 用户注册/登录/登出
- [x] 基础 CRUD（文章/资源管理）
- [ ] 文件上传（图片/头像）
- [ ] 分页与搜索
- [ ] 数据统计与报表
- [ ] 缓存优化
- [ ] 单元测试覆盖核心逻辑
- [ ] Docker 容器化部署

### 中级后端工程师（Mid-Level Backend）

- [ ] 设计高并发系统架构
- [ ] 数据库分库分表
- [ ] Redis 缓存策略设计
- [ ] 消息队列（RabbitMQ / Kafka）
- [ ] 微服务拆分与通信
- [ ] 全链路监控与告警

## 从当前状态到入门的推荐路径

| 阶段        | 内容                      | 时间   | 产出               |

## 关键认知

> 后端入门需要的不是"吃透某个工具"，而是**理解整个请求的生命周期**：
>
> ```
> 客户端请求 → Nginx → Node.js → 路由 → 中间件 → 校验 → 业务逻辑 → 缓存 → 数据库 → 返回响应
> ```
>
> 目前掌握了"路由 → 业务逻辑 → 数据库"这一段，继续向两边扩展即可。
